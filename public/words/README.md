# Word list

`enable.txt` is ENABLE (Enhanced North American Benchmark Lexicon, 1997),
a public-domain word list built for word games: 172,823 lowercase words, one
per line. The word checker answers from it first, so a verdict needs no
network, and asks the online dictionary only about words it doesn't hold
(ENABLE predates a few newer word-game words such as "qi" and "za").
Source: https://github.com/dolph/dictionary (enable1.txt).
